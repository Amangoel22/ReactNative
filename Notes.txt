1. Creating Project: npx create-expo-app --template blank ProjectName

2. To start expo app: npm start
    if phone and laptop on different network -> npx expo start --tunnel

3. Their can be some styling differences in Android and iOS like rounded corners, applying that to Text won't work on iOS, hence enclose it in View and then use.

4. ScrollView to enable scrolling.
   Downside: Good for limited content but if like list has 1000 entries, it renders all child components at once and can cause performance issues.

5. Solution to above: FlatList -> renders items on screen
   <FlatList data={courseGoals} renderItem={(itemData) => }

6. Pressable component is used to make an object pressable in a react app. Wrap the view in Pressable to make it pressable.

7. android_ripple won't work on ios, so we use style prop inside Pressable
style={({pressed}) => pressed && styles.pressedItem};
if pressed == true, apply styling as defined in Stylesheet.

8. Default react buttons are not much customisable hence we can use custom buttons using view and text to create buttons and cusomise as needed.

9. To add shadow, use elevation: 1,2,3... and for ios use we use shadow properties together.

10. Views only take space as needed by them by default.

11. Linear Gradient instead of Views to set linear gradient to any object. (2)

12. Dimensions API: import Dimensions, can be used in any JS file like an object 
                  const device_width = Dimensions.get('screen').width;

13. We can change app.json to adjust rotation.

14. KeyboardAvoidingView: when keyboard is open, moves content above so that we can view it. To apply, wrap parent View to KeyboardAvoidingView component.

15. To fix status bar import StatusBar from react-native and put it above and with root component and set style etc.

16. Platform API: import { Platform } from 'react-native' to run platform-specific code.
    Use Platform.OS === 'ios' / 'android' or Platform.select({ ios: ..., android: ... }) to apply platform-based values/styles.
    Alternatively, use platform-specific files like Title.android.js and Title.ios.js, React Native automatically selects the correct one when importing just './Title'.

18. Notifications:
   
   a. Local Notifications: Triggered by app on the device, not sent to other devices. -> install expo's notification package to run
   b. Push Notifications: Can send to other devices also, not directly but by using notification server or a backend.

   1. configure according to docs
   2. import * as Notifications from 'expo-notifications';
   3. Notifications.setNotificationsHandler({
      handleNotification:async() =>{
         return{
            shouldPlaySound: false,
            //more configs as needed,
         };
      }
   }); //done outside App()
   4. function scheduleNotificationsHandler(){
         Notifications.scheduleNotifications.Async({
            trigger:{
               seconds: 5,
            },
            content:{
               title:'custom content',
               body:'detailed text'
            },
         });
   }

   c. We can interact with notifications like tapping then what will happen we can use useEffect and event listeners.
   d. Push notifications use push tokens which are unique strings to identify devices.
   e. Permissions are needed when publishing apps.
